# Investigator Creator

A standalone, shareable character-creation wizard for **Call of Cthulhu** (1920s edition) — pick a gender, name, age, home, occupation, distribute characteristic and skill points, get equipment, and download a plain-text summary to copy onto a paper investigator sheet by hand.

This is a spin-off of the same tool built into [Keeper's Codex](https://github.com/daniilaksinin/keereps-codex), published separately so it can be shared with players via a plain link — no installation needed.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deploys automatically to GitHub Pages on every push to `main` via the workflow in `.github/workflows/deploy.yml`.
